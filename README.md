# operating-system-toolset

A collection of operating system productivity tools, configurations, and small utilities for macOS, Windows, and Linux.

This repository contains practical tools I use to improve daily system workflows, including shell shortcuts, folder metadata helpers, selective cross-device file sync, and lightweight Git automation.

## Tool List

- `1-zsh-alias`  
  Zsh command shortcuts for faster navigation, opening apps, and accessing frequently used folders.

- `2-folder-description`  
  A small utility for attaching descriptions to rarely used folders. The description is displayed in the terminal when switching into the directory. It can be removed with `rm .folder_description`.

- `3-selective-cross-device-file-sync`  
  A device-agnostic file synchronization setup for selected files and folders, designed to work with Google Drive.

- `4-git-combine-command`  
  A lightweight Git helper that simplifies the `add` → `commit` → `push` workflow into a single command using one commit-message argument.

## Platform Support

### Windows
- `3-selective-cross-device-file-sync`
- `4-git-combine-command`

### macOS
- `1-zsh-alias`
- `2-folder-description`
- `3-selective-cross-device-file-sync`
- `4-git-combine-command`

### Linux
This repository is intended to support Linux as well, with additional tooling to be expanded over time.

## Purpose

This repository is used to document and maintain practical operating-system-level tools that improve developer productivity and workflow efficiency.

The focus is on:
- shell productivity
- local system workflow improvements
- cross-device file management
- lightweight developer tooling
- small utilities with immediate practical value

This repository is actively updated as new tools, configurations, and small utilities are developed.
