# operating-system-toolset

My system setup tools, configuration and personal developed mini programs to help improving productivity, including MacOS and Windows platforms

### Tool List
- `1-zsh-alias` - some command shortcuts, including basic directory change, opening apps and folders
- `2-folder-descrition` - allows to write a description for rarely used folders, the description will display in terminal when switching to the directory. The description can be removed by `rm .folder_description`
- `3-selective-cross-device-file-sync` - device agnostic file synchronization system for selected files, work with Google Drive
- `4-zsh-git-combine-command` - simplifies the `git` add, commit and push operation, with only one argument as the commit message then automate the rest parts
